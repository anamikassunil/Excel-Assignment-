## Project: Healthcare Data Analysis and Insights

### Objective-

To clean and combine healthcare data, explore patient information,
identify patterns, and present useful insights through Excel charts and
an interactive dashboard.

### Dataset-

The project uses three related tables:

-   **Customer Names**
-   **Medical Examinations**
-   **Hospitalisation Details**

The tables are connected using **Customer ID**.

## Skills I Am Practising

-   Excel worksheet and table management
-   `COUNTIF` to count specific values
-   Finding the mode to fill missing categorical values
-   Handling missing values marked with `?`
-   Splitting names into Title, First Name, and Last Name
-   Using `VLOOKUP` to combine data from multiple worksheets
-   Creating calculated columns with formulas
-   Creating Pivot Tables
-   Building charts and an interactive dashboard

## Project Workflow

1.  **Data Cleaning**
    -   Count missing values in each column.
    -   Fill missing months with `Sep`.
    -   Replace missing years with the rounded average year.
    -   Find the most frequent values in Smoker, Hospital tier, and City
        tier.
    -   Handle missing State ID values appropriately.
2.  **Data Transformation**
    -   Split the Names column into Title, First Name, and Last Name.
    -   Convert major surgery information into numerical values.
    -   Check inconsistencies in Heart Issues and Smoker.
    -   Create Weight Status and Diabetes Status categories.
    -   Create Date of Birth and calculate Age.
    -   Format healthcare charges as currency.
3.  **Data Exploration and Analysis**
    -   Create a master worksheet named `Healthcare`.
    -   Combine the three tables using Customer ID and `VLOOKUP`.
    -   Retain the required columns for analysis.
    -   Use Pivot Tables to summarise the data.
4.  **Data Visualisation**
    -   Create pie or doughnut charts.
    -   Create column or bar charts.
    -   Create line or scatter plots.
    -   Build an interactive dashboard with slicers for Weight Status
        and Diabetes Status.
